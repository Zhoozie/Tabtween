## 1. 产品概述

### 1.1 产品名称

**页间（Tabtween）**（暂定名）

- **寓意**：页面之间，自在切换
- **Slogan**：页间自在，切换随心

### 1.2 产品定位

一款将浏览器新标签页从简单的导航页面升级为个人效率工作台，集成任务管理、信息聚合、知识管理等功能。

### 1.3 目标用户

| 用户群体   | 特征               | 核心需求                     |
| :--------- | :----------------- | :--------------------------- |
| 知识工作者 | 白领、研究者、学生 | 信息整合、快速记录、效率提升 |
| 效率追求者 | 创业者、自由职业者 | 任务管理、时间规划、专注工具 |
| 极简主义者 | 设计师、开发者     | 干净界面、高度定制、无干扰   |

## 2. 功能需求

| 名称         | 优先级 | 功能描述                       |
| ------------ | ------ | ------------------------------ |
| 智能布局     | P0     | 根据时间、场景自动切换布局模式 |
| 快捷访问管理 | P0     | 常用网站的快速访问与管理       |
| 待办事项清单 | P1     | 轻量级的任务管理功能           |
| 个性化主题   | P2     | 丰富的视觉定制选项             |

### 2.1 智能模式

- 支持两种模式：
  - 极简模式：极简时钟 + 搜索框
  - 标准模式：包含各种标准场景
    - 工作场景：任务列表 + 快捷工具 + 专注计时器
    - 学习场景：笔记区 + 阅读列表 + 知识卡片
    - 休闲场景：天气 + 新闻 + 推荐内容

####  2.1.1 极简模式

1. 默认状态

（1）极简时钟

**显示内容**：

- 大号时间显示（主要元素之一）
- 可选显示：日期、星期、秒钟
- 字体极简（细体或中等粗细）

**设计细节**：

- 时间格式：24小时制/12小时制可切换
- 字体大小：相对屏幕的40%-50%
- 颜色：白色或深色（根据背景自动调整）
- 位置：搜索框上方，垂直居中偏上

**交互特性**：

- 点击时间切换格式
- 长按进入设置
- 悬停显示日期详情

（2）搜索框

**默认状态**：

- 搜索框居中
- 内部显示搜索图标和提示文字
- 提示文字："搜索"（极简，无多余文字）
- 搜索引擎图标（可选显示）

**交互状态**：

- 未聚焦：极简外观
- 悬停：轻微亮度变化
- 聚焦：展开搜索结果面板
- 输入：实时显示搜索建议

2. 聚焦状态

**聚焦动画**：

- 搜索框宽度从40%扩展到60%
- 时钟淡出或上移缩小
- 背景略微变暗（聚焦效果）
- 搜索面板从搜索框下方滑出
- 过渡时间：200-300ms

**搜索建议类型与优先级**：

1. **搜索历史**（最近5条）
2. **快捷命令**（常用操作）
3. **智能推荐**（基于输入）
4. **热门搜索**（可选关闭）

**建议展示规则**：

- 最多显示8-10条
- 根据输入实时更新
- 键盘上下键选择
- 高亮匹配文字
- 右侧显示操作图标

###  2.2 模式切换

#### 2.1.1 切换逻辑

**第一层：大模式切换（极简 ↔ 标准）**

这是最高层级的切换，改变整个界面的设计理念。

**第二层：场景切换（标准模式下）**

在标准模式下切换具体场景（工作、学习、休闲）。

**切换动画**

**大模式切换（极简 ↔ 标准）**：

- 界面整体淡出（300ms）
- 界面整体淡入（300ms）
- 总时长：600ms
- 暗示"根本性变化"

**场景切换（标准内）**：

- 组件重新排列（400ms）
- 内容平滑过渡
- 总时长：400ms
- 暗示"调整而非改变"

1. 快捷键切换

**快捷键设计**：

- `Ctrl+M`：打开模式切换器
- `Ctrl+1`：切换到工作场景
- `Ctrl+2`：切换到学习场景
- `Ctrl+3`：切换到休闲场景
- `Ctrl+4`：切换到极简模式
- `Alt+←/→`：循环切换模式

2. 搜索命令切换

**命令设计**：

- 输入"工作"或"work" → 显示"切换到工作模式"
- 输入"学习"或"study" → 显示"切换到学习模式"
- 输入"休闲"或"relax" → 显示"切换到休闲模式"
- 输入"模式" → 显示所有模式选项

**交互流程**：

```
用户输入"工作"
    ↓
搜索建议显示："切换到工作模式 ⚡"
    ↓
按Enter或点击
    ↓
模式切换动画（300ms）
    ↓
进入工作模式
```



#### 2.1.2 模式切换动画

**切换动画设计**：

- 当前界面淡出（200ms）
- 新界面淡入（200ms）
- 总时长：400ms
- 缓动：ease-in-out

**动画细节**：

- 时钟缩放消失
- 搜索框位置调整
- 背景平滑过渡
- 新元素渐次出现

####  2.5.2 两种模式下的右上角设计

1. 极简模式下的右上角

```
┌─────────────────────────────────┐
│                    [🌓][🔄][⚙️]│ ← 30%透明度
│                                 │
│                                 │
│             14:30               │
│                                 │
│         [    搜索框    ]        │
│                                 │
│                                 │
└─────────────────────────────────┘
```

**交互细节**：

- 默认透明度：30%
- 悬停透明度：100%
- 过渡：200ms
- 图标大小：18px
- 间距：8px
- 距离右上角：16px

**可设置选项**：

- 完全隐藏（仅快捷键可呼出）
- 悬停显示（默认）
- 始终完全显示

2. 标准模式下右上角

```
┌─────────────────────────────────────────────┐
│ 🔍 搜索工作内容...    💼工作 [🌓][🔄][⚙️]│
├─────────────────────────────────────────────┤
│                                             │
│  （主内容区）                               │
│                                             │
└─────────────────────────────────────────────┘
```

**交互细节**：

- 默认透明度：100%
- 图标大小：16px
- 间距：6px
- 与场景指示器间距：12px
- 垂直居中于顶部栏

**设计特点**：

- 与顶部栏融为一体
- 图标风格统一
- 不占额外空间
- 始终可访问
